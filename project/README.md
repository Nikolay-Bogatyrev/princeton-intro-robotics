# Учебный проект: тренажёры к лекциям

К каждой встрече один ноутбук на 30–60 минут: короткая главная идея лекции, интерактивные ползунки, эксперименты и место для вопросов к встрече.

| Встреча | Ноутбук |
|---|---|
| 1 (12.10) | [01-graph-search.ipynb](01-graph-search.ipynb): BFS, Dijkstra, Greedy и A* на одной карте |

Тот же материал в браузере без Python — стенд в [`../site/`](../site/index.html).

## Как запустить

- **Google Colab:** откройте colab.research.google.com, выберите «Файл → Загрузить блокнот», затем «Среда выполнения → Выполнить все». Ничего ставить не нужно.
- **Локально:** `pip install numpy matplotlib ipywidgets jupyterlab`, затем `jupyter lab`.

## Проверка формата

Допущение: ноутбук с ползунками даёт понимание лучше, чем просто видео. После встречи 26.10 решаем, оставлять ли формат: открывались ли ноутбуки и откуда взялись вопросы к встречам.
